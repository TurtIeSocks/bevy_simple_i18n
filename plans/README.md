## Process notes from execution (2026-07-19)

  `[package]` with `[workspace] members = ["web"]` and sets no
  `default-members`, so a plain `cargo check --all-targets` does NOT compile
  the `web` member — use `cargo check --workspace --all-targets` when a plan
  touches `web/src/`. (CI's new wasm job does cover the web member.)

- **Formatter/plural-rules caching per locale** — `DecimalFormatter` and
  `PluralRules` are rebuilt per translate call (post-002: only when needed);
  a locale-keyed cache resource would help locale switches with thousands of
  text entities. Effort M, only worth it with a demonstrated hot path.

  precision above 2^53; a `Decimal`/integer-preserving constructor variant
  would fix it. Low demand until someone renders 64-bit currency values; also
  an API-design question for the maintainer (which constructor shape).

## Findings considered and rejected

- **Fluent / MessageFormat 2 support**: settled by design doc D6
  (`docs/systematic-refactor/design.md`) — bevy_fluent owns that niche; this
  crate's differentiator is "dead simple". Not a finding.
- **Manifest instead of folder scanning** (extra setup file): decided
  tradeoff, D1 — wasm/Android cannot enumerate asset directories.
- **No implicit fallback to default locale** (missing keys echo the key):
  decided tradeoff, D2/assumption 4 — rust-i18n parity; opt-in via manifest
  `fallback`.
- **Flat-merge divergence from rust-i18n deep-merge**
  (`src/parse.rs:56-63`): documented conscious divergence with tests; keeping
  both keys is the less surprising behavior.
- **`exclude = ["assets/"]` in Cargo.toml breaks packaged examples**: examples
  require a local assets dir by design; crates.io size matters more; users run
  examples from the repo.
